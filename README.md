# Tactical Pistol — Forge 1.20.1

Минимальный стартовый проект Forge для Java 17. Добавляет отдельную вкладку, пистолет-предмет, патроны 9×19 и предметы обвесов. Это базовая сборочная версия: анимации, HUD и применение обвесов ещё не реализованы.

## Сборка локально
1. Установите JDK 17.
2. Установите Gradle 8.8.
3. В корне проекта выполните `gradle build`.
4. JAR появится в `build/libs/`.

## Сборка через GitHub
Загрузите все файлы в репозиторий, сохранив `.github/workflows/build.yml`. Откройте вкладку **Actions** и выберите запуск `Build Tactical Pistol`. После зелёной галочки откройте запуск и скачайте artifact `Tactical-Pistol-1.20.1`. Внутри будет JAR.

## Установка
Поместите JAR в `.minecraft/mods`. Нужны Minecraft 1.20.1 и Forge 47.x.
